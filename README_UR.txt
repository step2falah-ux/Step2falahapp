Step2falah Pro Android Project (Version 1.1)

شامل:
- متحرک (animated) splash screen
- پلس/فِیڈ اینیمیشن والا پلے آئیکن
- سبز/سفید پروفیشنل ہوم اسکرین
- ویڈیو لنک پیسٹ کرنے اور اسے کھولنے کا بٹن
- فیچر کارڈز اور اردو انٹرفیس

اہم: یہ Android Studio سورس پروجیکٹ ہے، تیار شدہ APK نہیں۔ یہ YouTube کی پابندیوں کو بائی پاس نہیں کرتا اور ہر YouTube ویڈیو ڈاؤن لوڈ نہیں کرتا۔

APK بنانے کے لیے:
1. ZIP extract کریں۔
2. Android Studio میں Step2falah فولڈر Open کریں۔
3. Gradle sync مکمل ہونے دیں۔
4. Build > Build APK(s) منتخب کریں۔
5. APK: app/build/outputs/apk/debug/app-debug.apk

یہ پروجیکٹ Android SDK 35 اور Android Gradle Plugin 8.7.3 استعمال کرتا ہے۔
